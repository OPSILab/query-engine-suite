# Query Engine Suite

Query Engine Suite is a distributed system composed of two microservices:

- **Query Engine**
- **Source Connector**

It enables querying and synchronizing data from multiple heterogeneous sources such as:

- MongoDB
- PostgreSQL
- MinIO
- Orion
- External APIs

---

## Key Features

- GraphQL queries
- Advanced key-value search
- Full-text keyword search
- SQL queries
- JWT-based authentication
- Docker deployment support
